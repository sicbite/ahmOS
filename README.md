# ahmOS (Automated Hyprland OS)

An automated Arch Linux setup script for a minimalist and performant Hyprland desktop environment.

This project is built to automate the configuration of a minimalist, performant Hyprland environment with essential tools and optimizations, tailored for both bare metal and virtual machines.

**Note: This project was created with the assistance of GEMINI CLI.**

## Features
- **Minimalist & Performant:** A lean Hyprland setup.
- **Automated Installation:** Modular architecture for easy maintenance.
- **Robust Error Handling:** Network-aware scripts with logging.
